# 验收场景

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| M01 | 鼠标移入主按钮 | 保留油彩材质，轻微上浮/高光，不出现纯色块 |
| M02 | 鼠标移出后再次移入 | 动画可逆，不卡在 hover |
| M03 | 鼠标按下/松开 | pressed 压缩，clicked 果汁回弹，结果文案更新 |
| M04 | 快速连续点击 5 次 | 只有一个活动动画，无幽灵叠加或跳位 |
| M05 | Tab/Shift+Tab | focus-visible 焦点环清晰，文字不抖动 |
| M06 | 点击 disabled | 不触发主动作，不播放操作回弹，材质仍可见 |
| M07 | 点击加载 | loading 状态可见；再次点击被忽略或可取消 |
| M08 | 触控窄屏 | 无横向滚动，pressed/selected 反馈可见，按钮可触摸 |
| M09 | 切换 reduced motion | 动画立即降级为即时状态，仍有文案/图标/焦点反馈 |
| M10 | 点击 success/error | success 回弹，error 轻抖一次，均不覆盖文字 |
